# scrapeTx application audit — 17 October 2026

## Assessment

Suitable for continued local demos and research-workflow testing. This is not a certification of zero defects or readiness for an unrestricted public launch. Automated checks, real service calls, a native computation, and a production-container smoke test were performed. Browser access stopped during the final visual recheck; outstanding items are explicit below.

## Fixed

| Finding | Change |
| --- | --- |
| Docking completed but 3D preview failed with `protein.addStyle is not a function` | Use the installed GLModel `setStyle(selection, style, additive)` API. Added a test against the real 3Dmol package and 2,229-atom receptor. |
| Clearing a search could leave controls loading indefinitely; aborted requests could show stale errors | Reset loading/selection state and suppress responses from aborted requests. |
| Reopening older chats depended on the latest 500 global notes, silently losing older turns | Retrieve the exact chat and its turn IDs, with four concurrent requests, preserved order, and explicit missing-turn failures. |
| A rendering failure could blank the application | Add a tool-level recovery boundary and a root fallback; recovery does not clear workspace storage. |
| App edits could recreate context while lazy tools still referenced an old context | Extract the shared context into a stable module. |
| Rapid repeated library clicks could duplicate pending saves | Lock each pending paper mutation and deduplicate successful additions. |
| Production image omitted shared modules required by the server | Include `shared/` and docking example fixtures; exclude host `.tools/` from the build context. |
| Unknown API and asset URLs could receive the SPA HTML page | Return JSON 404 for unmatched API routes and 404 for missing compiled assets. |
| Fifteen flat navigation entries, hidden library, duplicate home guidance | Eight primary routes; visible Library and Docking; expandable writing and research groups; remove redundant start-project guidance. |
| Provider identities were generic symbols | Vendor original source-site icons with provenance, original colors, local delivery, and a failed-image fallback. |
| Writing tools implied AI-authorship detection | Rename visible tools to Writing Analysis and Writing Polish; preserve existing routes and disclose actual behavior. Remove artificial delayed text transformation. |
| Dialogs lacked an accessible title relationship | Link dialogs to their heading with `aria-labelledby`. |

## Validation performed

- 228 automated tests pass, including regression tests for search cancellation, recovery, saved chats beyond 500 turns, the installed molecular model API, and existing source/PDF/export/workflow/security tests.
- Production Vite build passes. 3Dmol remains an on-demand ~587 kB minified chunk and emits an upstream eval warning; it is not loaded by the home page.
- `npm audit` reports zero known vulnerabilities across production and development dependencies at audit time.
- `npm run verify:production`: isolated runtime staging based on Docker COPY directives, no user credentials or data; startup, deep links, source assets, API/asset 404s, origin rejection and missing-workspace-token rejection pass.
- Docker image `scrapetx:audit` built and ran locally without credentials. Health, workflow route, source logo, missing API/asset and missing-token checks passed. Test container stopped and removed.
- Storage create/read/update, cross-workspace isolation and missing-token rejection pass using disposable records; test records removed. Existing user records were not deleted.
- Real native AutoDock Vina example completed with four poses and best score −13.237 kcal/mol. The run is retained as **Audit check · 1IEP example** in the browser workspace. The score is a computational prediction, not a measured binding affinity.
- A live ScrapeTx AI guide request returned valid guidance and prioritized the molecular docking route.
- Live searches succeeded: Crossref (40 records), PubMed (20), PubChem aspirin (1), ClinicalTrials.gov (20), openFDA (15), arXiv (30), PyPI biopython (1), DataCite datasets (30).
- Desktop browser confirmed the simplified sidebar and successful loading of all ten provider-icon instances. No provider-image requests are needed after loading the app assets.
- Configured local environment credential values were not found in tracked files. `.env.local`, connector vaults and generated data remain ignored. This is not a complete historical secret scan.

## What still needs attention

1. **Final browser checks:** after browser control is re-enabled, recheck rendered docking poses, pose switching/zoom, mobile layout, and keyboard traversal. The original viewer failure was observed live; the fix is validated with the installed model API but not yet visually rechecked.
2. **Workspace-specific connectors:** a fresh disposable workspace correctly returns “connect SerpAPI” rather than borrowing another workspace's credentials. The user's Scholar, Zotero and Mendeley accounts were not reauthorized or retested in this audit. Recheck them in the connected browser workspace. AI/image status endpoints confirm configuration, not availability or quota.
3. **Public deployment:** decide on paid-provider budget limits and abuse protection for the deliberately login-free app; establish persistent storage, backups/restore testing and monitoring. The current per-process limits are not distributed quota enforcement. Browser workspace tokens are not account recovery or cross-device login.
4. **Container docking:** the container serves the app and example fixtures; native docking still requires the supported Linux Vina runtime installed/configured separately. The Mac executable is intentionally excluded.
5. **Maintainability:** `App.jsx` and four historical theme layers remain larger than desirable. Extract individual tools and consolidate styles incrementally with visual regression checks. Avoid another blanket theme rewrite.
6. **Large libraries:** exact chat reopening is fixed; collection list screens still use the existing 500-record listing cap. Add pagination before supporting very large libraries.
7. **Research quality:** metadata checks, source links and AI citations help review; they do not establish scientific correctness. Paid generation of images and a complete new paper/presentation were not rerun in this pass; existing export and citation tests passed.

## Repeatable checks

```sh
npm test
npm run build
npm run verify:production
npm audit
npm run verify:cloud
```

`verify:cloud` deliberately creates and deletes its own disposable records. The other checks do not need the user's API credentials. The updated `docs/github-actions.example.yml` template runs tests, build, isolated production checks and the production dependency audit. Automatic GitHub Actions activation is pending: the connected OAuth app lacks the `workflow` scope, so GitHub rejected creation of `.github/workflows/check.yml`. The application fixes can be pushed without expanding that access.
